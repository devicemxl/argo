# Type-Safe Generic Handles

One of Argo’s most compelling features is its type-safe handling of arrays. This is achieved through the use of generic handles, which provide a robust way to manage data without involving the garbage collector.

![image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*sduOi2cnYc2j1PjEou39iw.png)

This approach allows you to pass Go slices to C functions without any garbage collection involvement, ensuring efficient and safe memory management.
